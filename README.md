Upload a PDF, HTML, ZIP, or folder → get a `tinidrop.com` link. Password, NDA, eSignature, and page analytics sit on that link. Sites from `index.html` go live on `*.tinidrop.app`.

Languages: English, Spanish, Portuguese, German, French, Arabic, Japanese.
